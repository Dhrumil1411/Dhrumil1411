## About Me

I am a Computer Science and Engineering student (2nd-year B.Tech at KL University, previously completed a Diploma in Computer Engineering at Darshan University) focused on building practical web applications and software solutions.

My work centers around full-stack development, from designing responsive client interfaces to implementing backend services and database architectures. I have hands-on experience building real-time applications with WebSockets, developing browser extensions, and working with applied computer vision and machine learning pipelines. Having completed a web development internship, I prioritize clear project architecture, verifiable code, and software that directly solves real-world workflow challenges.

- **Current Focus**: Modern full-stack web applications (React, Node.js, FastAPI, PostgreSQL).
- **Core Interests**: Real-time communication, workflow automation, browser tooling, and applied computer vision.
- **Approach**: Pragmatic engineering, clean documentation, and honest evaluation of technical prototypes.

## Featured Projects

### [Web Chat App](https://github.com/Dhrumil1411/Web_Chat_App)
`Complete` • `Real-Time Messaging Application`

A real-time messaging web application developed during a web development internship. Features email and password authentication, 1-on-1 private messaging, group conversations, live unread message counters, user profile customization, and fluid modal transitions.

### [Doctor Diagnosis Assistant (DDA)](https://github.com/Dhrumil1411/Doctor-Diagnosis-Assistant)
`Research Prototype` • `Clinical Decision-Support Workstation`

A clinical decision-support workstation prototype that structures doctor-patient dialogues into standardized EHR records with Human Phenotype Ontology (HPO) codes. Features a 773-disease Bernoulli Naive Bayes classifier, multi-provider LLM differential reasoning fallback (Groq / OpenRouter) with in-memory payload caching, lab report attachments, and attending doctor review sign-off.

> **Disclaimer**: Research prototype and technical demonstration developed with public and synthetic datasets. Not certified medical software; does not provide direct medical diagnoses or clinical advice.

- **Stack**: FastAPI, React 19, Vite, PostgreSQL, Scikit-learn, SlowAPI, Docker
- **Repository**: [github.com/Dhrumil1411/Doctor-Diagnosis-Assistant](https://github.com/Dhrumil1411/Doctor-Diagnosis-Assistant)

---

### [ModiCam](https://github.com/Dhrumil1411/ModiCam)
`Complete` • `AI Face-Swapping Virtual Camera`

A real-time face-swapping desktop application that captures physical webcam video, detects facial landmarks, swaps the detected face with a target persona via deep learning models, dynamically adjusts frame rates to match hardware capacity, and streams the processed feed directly to OBS Virtual Camera for use in Zoom, Discord, and Microsoft Teams.

- **Stack**: Python 3.10+, OpenCV, InsightFace (`inswapper_128`), ONNX Runtime, MediaPipe, PyVirtualCam
- **Repository**: [github.com/Dhrumil1411/ModiCam](https://github.com/Dhrumil1411/ModiCam)

---

### [Nested Tic-Tac-Toe](https://github.com/Dhrumil1411/Nested_Tic_Tac_Toe)
`Complete` • `Multiplayer Web Game`

A real-time web implementation of Ultimate Tic-Tac-Toe where players compete on a 3×3 meta-board containing nine sub-boards. Each move dictates the sub-board the opponent must play on next. Includes real-time room creation and matchmaking over WebSockets, turn management, and win/draw condition evaluations.

- **Stack**: Node.js, Express, Socket.IO, Vanilla JavaScript, HTML5/CSS3
- **Repository**: [github.com/Dhrumil1411/Nested_Tic_Tac_Toe](https://github.com/Dhrumil1411/Nested_Tic_Tac_Toe)

---

### [KL Subject Code Replacer](https://github.com/Dhrumil1411/KL-Subject-Code-Replacer)
`Functional Utility` • `Browser Extension (Manifest V3)`

A Chrome extension built for KL University students that runs on the university's ERP portal (`newerp.kluniversity.in`). It converts cryptic course codes into readable subject titles, merges adjacent multi-hour lecture slots into continuous cards, provides a live class countdown widget, and calculates 85% attendance safety margins (safe bunks / required attendances).

- **Stack**: JavaScript, Chrome Extension Manifest V3, DOM MutationObserver, CSS
- **Repository**: [github.com/Dhrumil1411/KL-Subject-Code-Replacer](https://github.com/Dhrumil1411/KL-Subject-Code-Replacer)
